# JUZ40 — Апталық сабақ тапсыру анализі

Кураторлардың апта сайынғы Google Sheets кестелерін және Google Docs анализдерін бір жерге
жинап, ортақ анализ есебін автоматты шығаратын веб-қосымша. Деректер Postgres базасында
сақталады (Neon арқылы тегін алуға болады), сондықтан қосымшаны компьютерде де, Vercel-де де
бірдей іске қосуға болады.

> **Тез сынап көру керек пе?** `DATABASE_URL` қойылмаса, қосымша автоматты түрде локальді
> SQLite файлына (`data/app.db`) көшеді — Postgres баптамай-ақ бірден `python3 app.py` арқылы
> іске қосуға болады. Бұл тек локальді сынау үшін: Vercel-ге орналастырғанда `DATABASE_URL`
> міндетті түрде керек, әйтпесе деректер сақталмайды.

## 1. Дерекқор дайындау (бір рет қана)

Тегін Postgres алу үшін [neon.tech](https://neon.tech) сайтында аккаунт ашыңыз (GitHub/Google
арқылы кіруге болады) → **New Project** → жоба атауын беріп құрыңыз. Жоба құрылғаннан кейін
**Connection string** дегенді көшіріп алыңыз — ол мына түрде болады:

```
postgres://user:password@ep-xxxxx.aws.neon.tech/neondb?sslmode=require
```

## 2. Алғашқы баптау (бір рет қана)

Терминалда осы жоба папкасына өтіп, керек кітапханаларды орнатыңыз:

```bash
cd "/Users/kuanshernar/Desktop/АНАЛИЗ САЙТ"
python3 -m pip install -r requirements.txt
```

Жоба түбірінде `.env` файлын жасап (`.env.example` үлгісін көшіріп), Neon-нан алған сілтемені
қойыңыз:

```bash
cp .env.example .env
```

`.env` файлын ашып, `DATABASE_URL` мәнін өз Neon сілтемеңізге, ал `ADMIN_EMAIL`/`ADMIN_PASSWORD`
мәндерін сайтқа кіру үшін қолданғыңыз келетін email мен құпия сөзге ауыстырыңыз (сайт енді
кіру-шығу экранымен қорғалған).

## 3. Сайтты локальді іске қосу

```bash
cd "/Users/kuanshernar/Desktop/АНАЛИЗ САЙТ"
python3 app.py
```

Терминалда `Running on http://127.0.0.1:5050` деген жол шыққанда, браузерде мына сілтемені ашыңыз:

```
http://127.0.0.1:5050
```

Сайтты тоқтату үшін терминалда `Ctrl+C` басыңыз. Барлық деректер Neon-дағы Postgres базасында
сақталады — компьютерді ауыстырсаңыз да, деректер жоғалмайды.

## 4. Vercel-ге орналастыру (тегін)

1. **GitHub-қа жүктеу.** GitHub-та жаңа бос репозиторий ашыңыз (README-сіз), содан кейін:
   ```bash
   cd "/Users/kuanshernar/Desktop/АНАЛИЗ САЙТ"
   git remote add origin https://github.com/<сіздің-аккаунт>/<репозиторий-атауы>.git
   git push -u origin main
   ```
2. **Vercel-ге кіру.** [vercel.com](https://vercel.com) сайтында GitHub аккаунтыңызбен кіріңіз →
   **Add New → Project** → жаңа ғана жүктеген репозиторийді таңдаңыз → **Import**.
3. **Ортам айнымалыларын қосу.** Импорт бетінде **Environment Variables** бөліміне мыналарды
   қосыңыз:
   - `DATABASE_URL` — Neon-нан алған connection string
   - `SECRET_KEY` — кез келген ұзын кездейсоқ мәтін
   - `ADMIN_EMAIL` — сайтқа кіру логині
   - `ADMIN_PASSWORD` — сайтқа кіру құпия сөзі
4. **Deploy** батырмасын басыңыз. Бірнеше минуттан кейін Vercel сізге тұрақты сілтеме береді
   (мыс. `https://juz40-analytics.vercel.app`) — осы сілтемені кураторларға да бере аласыз.
5. Кодты өзгертіп, қайта `git push` жасаған сайын, Vercel сайтты автоматты түрде қайта
   орналастырады.

## 5. Апта сайынғы жұмыс тәртібі

Навигация иерархиясы: **Бағдарлама** (Smart / Junior) → **Поток** (Т-01, J-01...) → **Ай** →
**Апта** → («Кестені импорттау», «Нәтижелер», «Куратор анализі», «Ортақ анализ» — жеке бүйірлік
мәзірі бар бөлек парақтар).

Барлық потоктар мен апталар қосымша алғаш іске қосылғанда автоматты түрде дайын тұрады —
қолмен құрудың қажеті жоқ: әр потокта 5 ай (әрқайсысы 4 аптадан, барлығы 20 апта) алдын ала
жасалған («1-АЙ 1-АПТА» үлгісімен).

1. **Бағдарлама → Поток → Ай → Апта** — бас беттен бағдарламаны (мыс. Smart), содан кейін
   потокты (мыс. Т-01), содан кейін керекті айды және аптаны таңдаңыз. Апта таңдалғанда сайт
   тікелей «Кестені импорттау» бетіне өтеді.
2. **Рейтинг сілтемесін қосу** («Кестені импорттау» парағы) — әр Google Sheets кестесі бір
   «рейтинг» (жеке тест/аттестация нәтижесі) болып саналады, бір аптаға бірнешеуін кезекпен
   қосуға болады:
   - Google Sheets кестесін ашыңыз → **Файл → Ортаққа бөлу → Сілтеме алу** → рұқсатты
     «Сілтемесі бар кез келген адам → Көруші» етіп қойыңыз. Кестеде әр куратордың нәтижесі
     бөлек парақта (лист) болуы керек — бір кестеде 30-ға дейін парақ болуы мүмкін.
   - Сол сілтемені (және баған атауларынан «Максимум балл» табылмаса — әдепкі максимум
     балды) қойып, **«Анализ шығару»** батырмасын басыңыз. Бір батырма басу жеткілікті: сайт
     оқушы аты мен балл бағандарын әр парақтан автоматты түрде өзі анықтап, бірден импорттайды
     — қолмен баған таңдаудың қажеті жоқ. Әр парақтың атауы сол парақтағы оқушылардың куратор
     аты ретінде пайдаланылады (сондықтан парақтарды куратор атымен атаңыз).
   - Нәтиже дереу «Нәтижелер» бетінде шығады. Сол беттегі «+ Тағы рейтинг сілтемесін қосу»
     арқылы келесі рейтингті қосуға болады — барлық рейтингтердің нәтижесі сол бетте бірігіп
     көрсетіледі (алдыңғы импорттар жойылмайды, тек үстіне қосылады).
3. **Куратор анализін қосу** («Куратор анализі» парағы) — барлық кураторлардың анализі
   жазылған БІР ортақ Google Docs құжатының сілтемесін қойыңыз (құжатты «Ортаққа бөлу →
   Сілтемесі бар кез келген адам → Көруші» етіп ашық қылып қойған болу керек). Сайт құжаттың
   толық мәтінін өзі жүктеп алады. Құжатқа кейін жаңа куратор қосылса, осы жерде «Қайта
   жүктеу» батырмасын басыңыз.
4. **Талдау** («Нәтижелер» парағы) — импорттан кейін бірден автоматты есептеледі:
   - СТ ортақ балл (пайызбен және шикі баллмен);
   - ең жоғарғы балл жинаған, 0 балл жинаған, проходной (қола лига) жинай алмаған оқушы саны;
   - Алтын / Күміс / Қола лигасындағы оқушылардың саны және жалпы оқушы санына қатысты
     пайызы. Лига шектерін (әдепкі: алтын 90%, күміс 70%, қола/өту 50%) сол беттегі пішінде
     кез келген уақытта өзгертуге болады.
5. **Ортақ анализ есебі** («Ортақ анализ» парағы):
   - Пәндер бойынша баған-диаграмма, ең көп қателескен тақырыптар автоматты есептеледі;
   - «Кураторлардың жиынтық анализі» бөлімінде қосылған Google Docs құжатының толық мәтіні
     көрсетіледі;
   - Осының бәрін оқып, төмендегі «Жалпы қорытынды» өрісіне өз қорытындыңызды жазып сақтай
     аласыз.
5. **PDF/басып шығару** — «Ортақ анализ» парағының жоғарғы оң жағындағы «🖶 PDF ретінде сақтау»
   батырмасы браузердің баспа терезесін ашады, сол жерден «PDF ретінде сақтау» опциясын таңдауға
   болады.

## Ескертулер

- Балл бағанында сан емес мән бар жолдар (мыс. «келмеді», «-») автоматты түрде өткізіп жіберіледі
  және импорт нәтижесінде қанша жол өткізілгені көрсетіледі.
- Кестенің әр парағында (лист) бағандар аттары бірдей болуы керек (мыс. барлық парақта «Балл»
  деген баған болуы керек) — бағандарды сәйкестендіру бір рет жасалады да, барлық парақтарға
  бірдей қолданылады. Қандай да бір парақта таңдалған баған табылмаса, сол парақ өткізіп
  жіберіледі.
- «Өту пайызы» — әр жазба үшін (балл ÷ максимум балл × 100) осы пайыздан төмен болса, «өтпеді» деп
  есептеледі. Апта бетінің «Ортақ анализ» бөлімінде кез келген уақытта өзгертуге болады.
- Куратор Google Docs құжаты жалпыға ашық («Сілтемесі бар кез келген адам → Көруші») болуы керек
  — әйтпесе сайт мәтінді жүктей алмайды және «жүктелмеді» деген белгі қойып, себебін көрсетеді.
  Құжатты кейін жариялы еткен болсаңыз, «Куратор анализі» бетінде «Қайта жүктеу» батырмасын
  басыңыз.
- Кіру логині мен құпия сөзі кодта емес, тек `.env` файлында (локальде) және Vercel-дің
  Environment Variables бөлімінде (өндірісте) сақталады — сондықтан GitHub-тың ашық (public)
  репозиторийіне ешқашан жарияланбайды. Құпия сөзді ауыстырғыңыз келсе, осы екі жерде
  `ADMIN_PASSWORD` мәнін жаңартып, сайтты қайта іске қосыңыз.
