# JUZ40 — Апталық сабақ тапсыру анализі

Кураторлардың апта сайынғы Google Sheets кестелерін және Google Docs анализдерін бір жерге
жинап, ортақ анализ есебін автоматты шығаратын веб-қосымша. Деректер Postgres базасында
сақталады (Neon арқылы тегін алуға болады), сондықтан қосымшаны компьютерде де, Vercel-де де
бірдей іске қосуға болады.

> **Тез сынап көру керек пе?** `DATABASE_URL` қойылмаса, қосымша автоматты түрде локальді
> SQLite файлына (`data/app.db`) көшеді — Postgres баптамай-ақ бірден `python3 app.py` арқылы
> іске қосуға болады. Бұл тек локальді сынау үшін: Vercel-ге орналастырғанда `DATABASE_URL`
> міндетті түрде керек, әйтпесе деректер сақталмайды.

## 1. Дерекқор дайындау (бір рет қана)

Тегін Postgres алу үшін [neon.tech](https://neon.tech) сайтында аккаунт ашыңыз (GitHub/Google
арқылы кіруге болады) → **New Project** → жоба атауын беріп құрыңыз. Жоба құрылғаннан кейін
**Connection string** дегенді көшіріп алыңыз — ол мына түрде болады:

```
postgres://user:password@ep-xxxxx.aws.neon.tech/neondb?sslmode=require
```

## 2. Алғашқы баптау (бір рет қана)

Терминалда осы жоба папкасына өтіп, керек кітапханаларды орнатыңыз:

```bash
cd "/Users/kuanshernar/Desktop/АНАЛИЗ САЙТ"
python3 -m pip install -r requirements.txt
```

Жоба түбірінде `.env` файлын жасап (`.env.example` үлгісін көшіріп), Neon-нан алған сілтемені
қойыңыз:

```bash
cp .env.example .env
```

`.env` файлын ашып, `DATABASE_URL` мәнін өз Neon сілтемеңізге ауыстырыңыз.

## 3. Сайтты локальді іске қосу

```bash
cd "/Users/kuanshernar/Desktop/АНАЛИЗ САЙТ"
python3 app.py
```

Терминалда `Running on http://127.0.0.1:5050` деген жол шыққанда, браузерде мына сілтемені ашыңыз:

```
http://127.0.0.1:5050
```

Сайтты тоқтату үшін терминалда `Ctrl+C` басыңыз. Барлық деректер Neon-дағы Postgres базасында
сақталады — компьютерді ауыстырсаңыз да, деректер жоғалмайды.

## 4. Vercel-ге орналастыру (тегін)

1. **GitHub-қа жүктеу.** GitHub-та жаңа бос репозиторий ашыңыз (README-сіз), содан кейін:
   ```bash
   cd "/Users/kuanshernar/Desktop/АНАЛИЗ САЙТ"
   git remote add origin https://github.com/<сіздің-аккаунт>/<репозиторий-атауы>.git
   git push -u origin main
   ```
2. **Vercel-ге кіру.** [vercel.com](https://vercel.com) сайтында GitHub аккаунтыңызбен кіріңіз →
   **Add New → Project** → жаңа ғана жүктеген репозиторийді таңдаңыз → **Import**.
3. **Ортам айнымалыларын қосу.** Импорт бетінде **Environment Variables** бөліміне мыналарды
   қосыңыз:
   - `DATABASE_URL` — Neon-нан алған connection string
   - `SECRET_KEY` — кез келген ұзын кездейсоқ мәтін
4. **Deploy** батырмасын басыңыз. Бірнеше минуттан кейін Vercel сізге тұрақты сілтеме береді
   (мыс. `https://juz40-analytics.vercel.app`) — осы сілтемені кураторларға да бере аласыз.
5. Кодты өзгертіп, қайта `git push` жасаған сайын, Vercel сайтты автоматты түрде қайта
   орналастырады.

## 5. Апта сайынғы жұмыс тәртібі

Әр апта — жеке бүйірлік мәзірі бар бөлек парақ («Шолу», «Кестені импорттау», «Нәтижелер»,
«Куратор анализі», «Ортақ анализ»):

1. **Жаңа апта құру** — бас бетте апта атауын (мыс. «1-апта, 14–20 шілде»), мерзімін және өту
   пайызын енгізіп, «Апта құру» батырмасын басыңыз.
2. **Кестені импорттау** (әр куратор үшін бөлек, «Кестені импорттау» парағында):
   - Куратордың Google Sheets кестесін ашыңыз → **Файл → Ортаққа бөлу → Сілтеме алу** → рұқсатты
     «Сілтемесі бар кез келген адам → Көруші» етіп қойыңыз.
   - Сол сілтемені қойып, **«Алдын ала қарау»** батырмасын басыңыз.
   - Ашылған тізімдерден әр баған нені білдіретінін көрсетіңіз (Оқушы аты-жөні, Пән, Тақырып, Балл,
     Максимум балл, Куратор). Кестеде «Куратор» бағаны болмаса, жоғарыдағы «Бұл кестедегі куратор»
     өрісіне атын жазыңыз.
   - **«Осы кестені импорттау»** батырмасын басыңыз. Осыны әр куратордың кестесі үшін қайталаңыз —
     нәтижелер «Нәтижелер» парағында бір апта ішінде қосылып отырады.
3. **Куратор анализін қосу** («Куратор анализі» парағы) — куратор Google Docs-та жазған апта
   анализінен тиісті бөлікті көшіріп, сәйкес өрістерге қойыңыз (әр куратор үшін бөлек пішін
   толтырылады).
4. **Ортақ анализ есебі** («Ортақ анализ» парағы) — барлық кестелер мен кураторлар анализі
   қосылғаннан кейін автоматты түрде мыналар шығады:
   - Ортақ орташа балл (пайызбен және шикі баллмен) + пәндер бойынша баған-диаграмма;
   - Максималды балл алған оқушылар саны және кураторлардың түсіндірмесі;
   - Проходной балл жинамаған оқушылар саны және толық тізімі;
   - Ең көп қателескен тақырыптар (автоматты есептелген баған-диаграмма) + кураторлардың өз
     бақылауы;
   - Дайындыққа әсер еткен факторлар (кураторлар анализінен);
   - ҰБТ/СТ ортақ балл төмен болу себептері (кураторлар анализінен).
   - Осының бәрін оқып, төмендегі «Жалпы қорытынды» өрісіне өз қорытындыңызды жазып сақтай аласыз.
5. **PDF/басып шығару** — «Ортақ анализ» парағының жоғарғы оң жағындағы «🖶 PDF ретінде сақтау»
   батырмасы браузердің баспа терезесін ашады, сол жерден «PDF ретінде сақтау» опциясын таңдауға
   болады.

## Ескертулер

- Балл бағанында сан емес мән бар жолдар (мыс. «келмеді», «-») автоматты түрде өткізіп жіберіледі
  және импорт нәтижесінде қанша жол өткізілгені көрсетіледі.
- «Өту пайызы» — әр жазба үшін (балл ÷ максимум балл × 100) осы пайыздан төмен болса, «өтпеді» деп
  есептеледі. Апта құрғанда немесе есеп бөлімінде кез келген уақытта өзгертуге болады.
- Куратор Google Docs анализін әзірге қолмен көшіріп қою керек (Google Docs API арқылы автоматты
  тарту жоқ). Болашақта мұны, бірнеше пайдаланушыға арналған кіру жүйесін немесе AI негізіндегі
  мәтіндік қорытынды жасауды қосуға болады.
