# JUZ40 — Апталық сабақ тапсыру анализі

Кураторлардың апта сайынғы Google Sheets кестелерін және Google Docs анализдерін бір жерге
жинап, ортақ анализ есебін автоматты шығаратын локальді веб-қосымша.

## 1. Алғашқы баптау (бір рет қана)

Терминалда осы жоба папкасына өтіп, керек кітапханаларды орнатыңыз:

```bash
cd "/Users/kuanshernar/Desktop/АНАЛИЗ САЙТ"
python3 -m pip install -r requirements.txt
```

## 2. Сайтты іске қосу

```bash
cd "/Users/kuanshernar/Desktop/АНАЛИЗ САЙТ"
python3 app.py
```

Терминалда `Running on http://127.0.0.1:5050` деген жол шыққанда, браузерде мына сілтемені ашыңыз:

```
http://127.0.0.1:5050
```

Сайтты тоқтату үшін терминалда `Ctrl+C` басыңыз. Барлық деректер `data/app.db` файлында сақталады —
қосымшаны жауып, келесі жолы қайта ашсаңыз да деректер жоғалмайды.

## 3. Апта сайынғы жұмыс тәртібі

1. **Жаңа апта құру** — бас бетте апта атауын (мыс. «1-апта, 14–20 шілде»), мерзімін және өту
   пайызын енгізіп, «Апта құру» батырмасын басыңыз.
2. **Кестені импорттау** (әр куратор үшін бөлек):
   - Куратордың Google Sheets кестесін ашыңыз → **Файл → Ортаққа бөлу → Сілтеме алу** → рұқсатты
     «Сілтемесі бар кез келген адам → Көруші» етіп қойыңыз.
   - Сол сілтемені апта бетіндегі «1. Google Sheets кестесін импорттау» бөліміне қойып, **«Алдын ала
     қарау»** батырмасын басыңыз.
   - Ашылған тізімдерден әр баған нені білдіретінін көрсетіңіз (Оқушы аты-жөні, Пән, Тақырып, Балл,
     Максимум балл, Куратор). Кестеде «Куратор» бағаны болмаса, жоғарыдағы «Бұл кестедегі куратор»
     өрісіне атын жазыңыз.
   - **«Осы кестені импорттау»** батырмасын басыңыз. Осыны әр куратордың кестесі үшін қайталаңыз —
     нәтижелер бір апта ішінде қосылып отырады.
3. **Куратор анализін қосу** — куратор Google Docs-та жазған апта анализінен тиісті бөлікті
   көшіріп, «3. Кураторлардың сапалы анализі» пішінінің сәйкес өрісіне қойыңыз (әр куратор үшін
   бөлек пішін толтырылады).
4. **Ортақ анализ есебі** — барлық кестелер мен кураторлар анализі қосылғаннан кейін, «4. Ортақ
   анализ есебі» бөлімінде автоматты түрде мыналар шығады:
   - Ортақ орташа балл (пайызбен және шикі баллмен);
   - Пәндер бойынша орташа балл және өтпегендер саны;
   - Максималды балл алған оқушылар саны және кураторлардың түсіндірмесі;
   - Проходной балл жинамаған оқушылар саны және толық тізімі;
   - Ең көп қателескен тақырыптар (автоматты есептелген) + кураторлардың өз бақылауы;
   - Дайындыққа әсер еткен факторлар (кураторлар анализінен);
   - ҰБТ/СТ ортақ балл төмен болу себептері (кураторлар анализінен).
   - Осының бәрін оқып, төмендегі «Жалпы қорытынды» өрісіне өз қорытындыңызды жазып сақтай аласыз.
5. **PDF/басып шығару** — апта бетінің жоғарғы оң жағындағы «🖶 Есепті PDF ретінде сақтау» батырмасы
   браузердің баспа терезесін ашады, сол жерден «PDF ретінде сақтау» опциясын таңдауға болады.

## Ескертулер

- Балл бағанында сан емес мән бар жолдар (мыс. «келмеді», «-») автоматты түрде өткізіп жіберіледі
  және импорт нәтижесінде қанша жол өткізілгені көрсетіледі.
- «Өту пайызы» — әр жазба үшін (балл ÷ максимум балл × 100) осы пайыздан төмен болса, «өтпеді» деп
  есептеледі. Апта құрғанда немесе есеп бөлімінде кез келген уақытта өзгертуге болады.
- Бұл — негізі (foundation) нұсқа: деректер локальді компьютерде сақталады, куратор Google Docs
  анализін өзіңіз (немесе куратордың өзі) сайтқа қолмен көшіріп қою керек. Болашақта Google Docs
  API арқылы автоматты тартуды, бірнеше пайдаланушыға арналған кіру жүйесін немесе AI негізіндегі
  мәтіндік қорытынды жасауды қосуға болады.
